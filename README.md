# Hometown Guidebook

Hometown Guidebook is a relocation and local-discovery website beginning with South Carolina.

This repository is the source of truth for the site. It includes the launch V1 site structure, researched city profiles, comparison pages, relocation guides, local-service directory scaffolding, methodology, sources, SEO files, and the Hometown Match prototype.

## Deployment

The site is intended to deploy automatically to Vercel from the `main` branch.

## Editorial standard

Objective data should be sourced to authoritative sources. Hometown Guidebook editorial analysis and sponsored business placement must remain clearly distinguished from sourced facts.
